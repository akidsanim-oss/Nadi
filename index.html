Pipeline World Models
De la capture à la simulation physique : notre API génère des environnements entraînables.
spatial_pipeline.py 
# 1. Capture depuis n'importe quel smartphone
from immersity import SpatialCapture

capture = SpatialCapture.from_image("photo.jpg")
depth = capture.estimate_depth(model="v2-large") # <12ms
cloud = depth.to_pointcloud()

# 2. Génère un World Model entraînable
world = cloud.to_world_model(
  physics=True,
  semantics=True
)

# 3. Entraîne ton agent
agent.train(world, epochs=100)
Pipeline testé sur 12 architectures • Compatible PyTorch, JAX, Genesis
